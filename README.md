# Poke-Portfolio
PokéPortfolio is a strategy-based finance game where players manage a dynamic portfolio of Pokémon using PokéCoins in an ever-changing market.

game/
 ├─ pokemon_db.py        # All Pokémon data
 ├─ player.py            # Player info, balance, inventory
 ├─ market.py            # Market mechanics: daily random fluctuations, inventory
 ├─ news.py              # Generates & tracks news events affecting market prices
 └─ game.py              # Main game loop
